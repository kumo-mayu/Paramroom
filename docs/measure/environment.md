# 測定に使った環境

fps・フレーム時間・Animator の負荷・符号化や探索の時間は、機械によって大きく変わる。`docs/` の数値を
自分の環境と比べるときは、ここに書いた機械で測った値だと考えて読むこと。画質の指標（MS-SSIM・PSNR）や
ビット数、取りこぼしの有無のような「機械によらない」値はこの限りではない。

スペックは 2026-09-19 に確かめたもの。それ以前の測定のときに、ドライバや VRChat の版が同じだったとは限らない。

## どの数値をどの機械で測ったか

| 文書 | 数値 | 機械・条件 |
|---|---|---|
| `docs/research/13`（2026-09-19） | VRChat の fps・転送時間・復号時間・写真 | **メイン PC**。デスクトップモード、窓 2560×1369、利用者のホームのワールド（静かな室内）。前半は fps 上限 60、途中から上限なし（表ごとに書いた） |
| `docs/research/13` | Unity の Animator.Update の時間 | **メイン PC**、Unity エディタの batchmode（VRChat の中の値とは別。傾向を見るためのもの） |
| `docs/research/13` | lpic の符号化時間（0.15〜0.3 秒） | **メイン PC**、node、1 スレッド |
| `docs/research/12` | 符号化時間（JS・C#） | **記録なし**。メイン PC とサブ PC のどちらも使える状態で測っており、どちらかは分からない |
| `docs/research/10`（2026-09-18） | fps と OSC の取りこぼし | 機械の記録なし。VRChat はメイン PC で動かしているので、メイン PC と考えられる [推測] |
| `docs/measure/results-2026-09-17*.md` | 保持時間・欠落・半端パケット | 「同じ PC 上の 2 クライアント」（`--fps=60`、960×540）。機械の記録なし。メイン PC と考えられる [推測] |
| `docs/research/08` §10、`tools/Paramroom.Core/PrimEncoder.cs` のコメント | C# の符号化時間 | 「Ryzen、16 スレッド」とだけ記録。メイン PC かサブ PC かは分からない |

以後の測定では、数値と一緒に「どの機械で」を書き、機械が変わったらこの表を更新する。
