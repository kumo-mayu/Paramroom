# BOOTH 商品画像の構成と撮影リスト

`item-page.md`（文面）と対になる、商品画像の設計。撮影はユーザーが実機で行う。

## 前提

- **比率は 1:1、1000×1000 px 以上**で作る。BOOTH の一覧は正方形で表示される
  （1:1 推奨・1000px 推奨は公式ではない記事による。未確認）
- **X で共有すると横長（約 1.91:1）に切られる**という助言がある（未確認。中央で切られるかも未確認）。
  1000×1000 なら、**大事な文字は縦の中央 520 px（y = 240〜760）に収める**と、どちらでも欠けにくい
- ショップの既存 2 商品に合わせる：
  - なでシェーダー：白地に黒の太い文字だけ
  - 水底シェーダー：実機のスクリーンショットに大きな文字を重ねる
- **送る画像に他人の著作物を使わない。** 自作のイラスト・写真か、CC0 の画像にする。
  リポジトリの比較画像（`measure/results/`）は CC BY-SA の元画像を含むので使わない
- 撮影に使うアバターのクレジットを `item-page.md` の「クレジット」に書く

## 1 枚目：サムネイル

一覧で目に留まるのは 1 枚目だけなので、**「何ができるか」が一目で分かること**を最優先にする。

### 案 A（おすすめ）：実機のスクリーンショットに文字を重ねる

表示板に絵がはっきり出ている実機の画面を背景にする。水底シェーダーと同じ作り。

```
┌──────────────────────────────┐
│ Paramroom                     │ ← 上部：商品名（大）
│ 画像とQRコードを               │
│ アバターで見せる               │
│                               │
│   [アバター]   [表示板に       │ ← 中央（y 240〜760）：
│                 送った絵]      │    アバターと表示板。ここが主役
│                               │
│ 無料・MA対応                   │ ← 下部：帯
│ 同期パラメータだけで送る        │
└──────────────────────────────┘
```

- 背景：アバターの横に表示板があり、**完成した絵がはっきり見える**画面
- 送る絵は、**遠くからでも何か分かる、色のはっきりした画像**。細かい文字や写真の細部は近似で潰れるので避ける
- 文字の案（どれか 2〜3 個）：
  - 「画像とQRコードをアバターで見せる」
  - 「無料・MA対応」
  - 「同期パラメータだけで送る」
  - 「ワールド対応不要」

### 案 B：「送る前」と「届いた絵」を並べる

```
┌──────────────────────────────┐
│ Paramroom                     │
│                               │
│  [元の画像] ──256bit──▶ [表示板] │ ← 中央：左に PC の画像、右に VRChat の表示板
│                               │
│ 無料・MA対応                   │
└──────────────────────────────┘
```

- 仕組みは伝わるが、実機の画面が小さくなり、VRChat のギミックらしさが薄れる

### 案 C：文字だけ（なでシェーダーと同じ）

```
┌──────────────────────────────┐
│ Paramroom                     │
│   画像とQRコードを             │
│   アバターで見せる             │
│                               │
│ 無料・MA対応                   │
│ 同期パラメータだけ              │
└──────────────────────────────┘
```

- 作るのは一番楽。ただ「絵が出る」ギミックなのに絵が無いので、案 A より弱い

**おすすめは案 A。** 実機のスクリーンショットが用意できるなら、それを主役にするのが一番伝わる。

## 撮影リスト（実機）

| 撮るもの | 条件 | 使う画像 |
|---|---|---|
| 完成した絵とアバター（サムネ用） | 形式 4 ＋ Int 32 個、送信間隔 100 ms。表示板が画面の中央に大きく入る構図 | 1 |
| 描かれていく途中（開始直後・10 秒・20 秒・完成） | 上と同じ。**カメラを固定**し、送信開始からの秒数を控えておく | 2 |
| QR コードをスマートフォンで読む | 鏡の前で。スマートフォンに読み取り結果が出ている瞬間 | 3 |
| Decoder Builder の画面 | アバターを選んだ状態。形式 4 が「おすすめ」と出て、空きビット数が見えている | 6 |
| 送信アプリの画面 | 画像を読み込んだ状態（1 周の秒数が出ている） | 4 |

- 相手視点の絵は**別の PC のアカウント**（フレンドか Show Avatar 済み）から撮る。自分の視点でも表示板は見えるが、
  「相手にどう見えるか」を示すなら相手視点のほうがよい
- **送信アプリの画面はこちらでも撮れる**（`ui-check` スキル。宛先を 127.0.0.1 に固定するので VRChat へは送らない）。
  送る画像を指定してもらえれば用意する
