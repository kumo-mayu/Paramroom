# paramroom

VRChat のアバターに、**PC の画像や QR コードを送って見せる**ギミックです。

VRC+ の Prints と違って **VRChat の中で撮った写真に限りません**。PC にある画像ファイルや、ブラウザから
ドラッグしてきた画像、URL から取ってきた画像を、そのまま相手に見せられます。ワールド側の対応も要りません。

アバターの**同期パラメータ（Int を最大 32 個 = 256 bit）だけ**を使い、画像を図形の並びに置き換えて
100 ms ごとに少しずつ送ります。受け取る側のアバターがそれを絵に描き直します。

- **画像**：10〜20 秒でだいたい分かる絵になり、100 秒ほどで全部揃います
- **QR コード**：**1 秒かからず**に出ます（URL を渡すのに向いています）

## 先に知っておいてほしいこと

できないこと・向かないことがあります。導入前に確認してください。

- **相手からは、フレンドか「Show Avatar」を押した人にしか見えません。** アバター上のカメラがリモートで
  動く条件がそれだからです。
- **PC 専用です。Quest / Android では動きません**（カメラもカスタムシェーダーも無効になります）。
- **同期パラメータを最大 32 Int（256 bit）使います。** アバターの空きに収まる数を選んでください
  （少ない Int でも動きますが、そのぶん 1 周が長くなります）。
- **画像は 100 秒ほどかかります。** 会話の合間にさっと見せる用途には向きません（QR コードなら一瞬です）。
- **相手が「遠すぎる」「表示人数制限」でこちらを隠している間は進みません。** 表示に戻れば描き直されます。
- **同じアバター（同じ blueprint ID）を 2 人以上が着ていると絵が壊れます。** VRChat がカメラループの
  RenderTexture をアバター単位で共有するためです。配布アバターに組み込んで配ることはできません
  （各自が自分のアバターに入れてアップロードする形なら問題ありません）。
- **絵は粗くなります。** 写真そのままではなく、図形を重ねた近似です。

## 利用上の注意

送信する画像について、必要な著作権その他の権利・許諾を確認して使用してください。第三者の権利を侵害する画像や、
VRChat の [Terms of Service](https://hello.vrchat.com/legal) /
[Community Guidelines](https://hello.vrchat.com/community-guidelines) /
[Creator Guidelines](https://hello.vrchat.com/creator-guidelines) に反するコンテンツの送信には使用しないでください。

## 必要なもの

| もの | 備考 |
|---|---|
| Unity ＋ VRChat SDK (Avatars) | アバターをアップロードできる環境。動作確認は Unity 2022.3.22f1 / SDK 3.10.4 |
| [Modular Avatar](https://modular-avatar.nadena.dev/) | プレハブを置くだけでパラメータとアニメーターが入ります。1.17.1 で確認 |
| アバターの同期パラメータの空き | **Int 32 個（256 bit）**が理想。少ない数でも動きます |
| Windows PC と .NET 9 | 送信アプリ（`tools/ImagePad.App`）を動かすため |
| VRChat の OSC が有効 | 送信アプリがアバターのパラメータを動かすのに使います |

## 入れかた

1. `measure/unity/Assets/ImagePad` を、アバターのプロジェクトの `Assets/` に入れる。
2. ヒエラルキーでアバター（またはその子）を選ぶ。
3. **Tools/ImagePad/Prim Decoder Builder** を開く。アバターの同期ビットの空きが表示されるので、
   収まる Int 数を選んで作る（**迷ったら形式 3 ＋ 32 Int**）。
4. できた `ParamroomDecoder*.prefab` をアバターの直下に置く。
5. 表示板（`Display`）を見せたい位置・大きさに動かす。
6. アバターをアップロードする。

詳しくは [`measure/unity/Assets/ImagePad/README.md`](measure/unity/Assets/ImagePad/README.md) を見てください。

## 使いかた

1. VRChat を起動し、上のアバターに着替える。
2. 送信アプリを起動する。アバターは自動で見つかります（VRChat を後から起動しても大丈夫です）。
3. 画像を指定する：**ファイルを選ぶ**／**URL を入れる**／**ブラウザや エクスプローラーからドラッグ**／
   **Ctrl+V で貼り付け**のどれでも。
4. 文字列を QR コードにしたいときは、QR の欄に入れて「QR コードにする」。
5. 「送信を始める」。相手のアバターに少しずつ絵が出ます。

**人が多い場所では送信の間隔を伸ばしてください**（アプリで変えられます）。混んでいるとパケットを
取りこぼしやすく、100 ms のままだと逆に遅くなります。

## 仕組み（簡単に）

画像をそのまま送るには 256 bit は狭すぎるので、**画像を「色のついた楕円 4000 個」に置き換えて**送ります。
楕円は「絵の狂いが大きく減る順」に選ばれるので、**途中まででも意味の分かる絵**になります。1 パケットは
それ自体で完結していて、順番も取りこぼしも気にしません。

QR コードのときは、白黒の升目そのものをパケットに載せます（画像として送るより 40〜100 倍速い）。

設計と実測の記録は `docs/` にあります。
